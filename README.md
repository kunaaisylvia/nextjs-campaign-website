# 🗳️ Next.js Campaign Website

A modern, responsive campaign website built with **Next.js**, **TypeScript**, and **Tailwind CSS**. Designed with a premium user experience, clean architecture, and scalable components to showcase a professional political campaign platform.

---

## ✨ Features

- Modern responsive design
- Interactive hero section
- Leadership journey timeline
- About section
- Mobile-first experience
- Reusable UI components
- Clean project architecture
- Smooth animations (coming soon)

---

## 🛠 Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- shadcn/ui
- Lucide React

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/kunaaisylvia/nextjs-campaign-website.git
```

Navigate to the project:

```bash
cd nextjs-campaign-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
